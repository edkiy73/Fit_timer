# UnMute — план редизайна интерфейса

Статус: **согласован владельцем** (2026-09-30), все шесть решений §7 — «да». D0 сделан (см. §6). Основа — навык
`.claude/skills/premium-mobile-ui`, стек из ADR (React + Vite + React Aria в Capacitor WebView).
Каждый этап ниже = один PR; после каждого — скриншоты «до/после» (390×844 и 412×915, обе темы,

## 1. Для кого мы рисуем

**Кто:** русскоязычные взрослые 25–45 лет, переехавшие за границу (часто IT и специалисты, пары и
семьи). Английский «читаю, понимаю, но молчу». Задачи — живые ситуации: кафе, арендодатель,
врач, коллеги, small talk на вечеринке.

**Как занимаются:** короткими подходами 10–15 минут — утром, в дороге, вечером после работы;
в основном с Android-телефона, одной рукой.

**Что чувствуют:** страх заговорить («немота» — отсюда и UnMute), усталость от детских
игрофицированных приложений, нехватка времени. Хотят взрослого, спокойного, «дорогого» продукта,
который показывает реальный прогресс, а не сову с уговорами.

**Следствия для дизайна**

| Инсайт | Решение |
|---|---|
| Страх говорить | Голос — главный герой: крупная тактильная кнопка микрофона, мягкая обратная связь, ошибки без красных «крестов» |
| Взрослые, не дети | Спокойная тёмная база, один тёплый акцент, никакой мультяшности и конфетти |
| Мало времени | «Сегодня» отвечает на один вопрос — что сделать сейчас; оценка времени на урок |
| Переезд — это путь | Курс = маршрут с остановками, а не таблица из 40 карточек |
| Вечер и дорога | Тёмная тема полноценная и основная по ощущению; светлая — тёплая «бумага», а не белый офис |
| Одна рука | Навигация внизу, главное действие внизу экрана, цели касания ≥ 48 px |

## 2. Палитра «Signal» (замена временной бирюзовой)

Идея: **коралловый «сигнал голоса»** (тепло, смелость, «эфир включён», но не тревожный красный) на
**глубоком чернильном** фоне (спокойствие, фокус, вечер). Три служебных цвета со своим смыслом:
мятный — правильно, небесный — слушание, янтарный — серия дней. Отличается от зелёного Duolingo,
оранжевого Babbel и фиолетового FitTimer.

| Токен | Тёмная | Светлая | Роль |
|---|---|---|---|
| `--bg` | `#12131C` | `#FBF7F2` | фон |
| `--card` | `#1C1D2A` | `#FFFFFF` | поверхность, тайлы |
| `--surface` | `#262738` | `#F3EDE5` | вложенные зоны, поля |
| `--line` | `#33344A` | `#E6DED3` | границы |
| `--ink` | `#F3EEE8` | `#1B1A24` | основной текст |
| `--muted` | `#A7A3B3` | `#625E70` | вторичный текст |
| `--accent` | `#FF7A59` | `#FF7A59` | главные кнопки, текущая станция, ссылки на тёмной |
| `--accent-ink` | `#FF7A59` | `#C2412A` | коралловый текст/ссылки |
| `--on-accent` | `#1A0F0B` | `#1A0F0B` | текст на коралловой кнопке |
| `--success` | `#4BD6A0` | `#137A56` | правильный ответ, пройденное |
| `--listen` | `#7FB2FF` | `#2F63C8` | аудирование, озвучка |
| `--streak` | `#FFC15A` | `#8A5A00` | серия дней |
| `--locked` | `#75728A` | `#8A8499` | закрытые станции, неактивное |

Проверено по WCAG 2.2: текст ≥ 4.5:1 (основной 16:1, вторичный 5.9–7.5:1, коралловый текст
4.8–7.2:1, текст на коралловой кнопке 7.3:1); неактивные элементы ≥ 3:1. Белый текст на коралле
не используем (4.3:1). Акцент редкий: коралловым красится только главное действие экрана и
«ты здесь» на карте.

Токены живут в `config/product.json → brand.ui` (применяет `src/theme.ts`) и CSS-переменных;
в компонентах ни одного hex.

**Типографика:** Manrope (кириллица + латиница, современный гротеск) — заголовки 800, текст 500;
шрифт кладём локально (woff2, подмножества cyrillic + latin, ~2×40 КБ), чтобы работало без сети в
приложении; обязательный системный fallback. Шкала M3: display 34, headline 28, title 20,
body 16, label 13. Цифры — `tabular-nums`.

**Иконки:** своей системы иконок в UnMute нет — заводим одну: inline SVG 24 px, линия 1.75,
скругления (стиль Lucide), компонент `Icon` с набором ~20 иконок. Без эмодзи.

## 3. Навигация

**Нижняя панель (стекло, 4 вкладки)**, скрывается внутри урока:

| Вкладка | Что внутри |
|---|---|
| **Сегодня** | главный экран |
| **Маршрут** | карта курса |
| **Повтор** | повторения + «Мои слова»; бейдж с числом карточек к повтору |
| **Я** | прогресс, активность, настройки, аккаунт |

- Убираем глобальную шапку «Английский для жизни / UnMute» с каждого экрана: у экрана свой
  крупный заголовок (M3 large top bar), при прокрутке сжимается в стеклянную полосу.
- Урок, диалог и разговор с ИИ — полноэкранный режим без панели: сверху «закрыть» и сегментный
  прогресс, снизу закреплённая кнопка действия.
- Всплывающие окна (словарь, результат ответа, подтверждения) — bottom sheet с пружиной;
  системная «Назад» закрывает окно первым.
- Переходы между вкладками — View Transitions (плавная смена), где нет API — мгновенно.

## 4. Экраны

### 4.1 Сегодня (bento)

```
┌───────────────────────────┐
│ День 7 · Past Simple      │  ← главный тайл 2×2, коралловая кнопка
│ «Расскажи, что делал вчера»│
│ 14 заданий · ~12 мин      │
│ [ Продолжить ▶ ]          │
├─────────────┬─────────────┤
│ 🔥 Серия 5  │ Повтор 18   │  ← 1×1: серия (неделя точками), повтор (кнопка)
│ ●●●●●○○     │ [ Начать ]  │
├─────────────┴─────────────┤
│ 🎙 Скажи вслух сегодня    │  ← 2×1: разговорное задание дня из плана
├───────────────────────────┤
│ Впереди: диалог «Кафе»    │  ← 2×1: ближайшая особая станция маршрута
│ через 3 дня               │
└───────────────────────────┘
```
(значки в схеме условные — в интерфейсе SVG-иконки)

- Одно главное действие — продолжить день; повтор вторым по весу, если он есть.
- Пустые состояния честные: нет повторов — тайл «Повтор» не показывается, а не «0».
- Загрузка — shimmer тех же форм; из кэша — сразу данные.

### 4.2 Маршрут — карта курса как линия метро

Вместо 40 карточек — **один маршрут переезда**: вертикальная извилистая линия (SVG),
станции-дни, 9 районов-этапов. Этапы уже есть в курсе: остановки-повторы стоят каждые 4–5 дней.

| Этап | Дни | Название | Темы |
|---|---|---|---|
| 1 | 1–6 | Старт | помощники, вопросы, Present Simple/Continuous, фразы-спасатели |
| 2 | 7–10 | Вчера | Past Simple, сборка вопроса, как продлить фразу |
| 3 | 11–15 | Планы | will / going to, have to, can / could, should |
| 4 | 16–19 | Вежливо | would, Present Perfect, used to |
| 5 | 20–23 | Беглость | сокращения, at / on / in, хвосты глаголов |
| 6 | 24–27 | Быт | артикли, there is / it is, have / take / make / do |
| 7 | 28–31 | Дом | бытовые действия, get, «который / где» |
| 8 | 32–35 | Истории | рассказ, сравнение, смягчить и усилить |
| 9 | 36–40 | Финиш | просьбы, should have, if, рассказ о себе, ошибки |

**Станции и их вид**

| Станция | Вид |
|---|---|
| Урок | круг |
| Повтор (дни 6, 10, 15…) | двойной круг — «пересадка» |
| Диалог-сценка (дни 9, 17, 25, 33) | ориентир с иконкой реплики и названием («Кафе и заказ») |
| Разговор с ИИ (дни 6, 15, 23, 31, 35) | иконка микрофона |
| Финал (день 40) | флаг, «конечная» |
| Пройдено | заливка `--success`, линия сплошная |
| Ты здесь | коралловое кольцо с мягкой пульсацией + плашка «Ты здесь» |
| Впереди | контур, линия пунктиром |
| Закрыто полным курсом | `--locked` + «турникет» после дня 7: «Дальше — полный курс» |

- Текущий этап раскрыт, остальные свёрнуты в строку района: название, темы-чипы, кольцо
  прогресса «4/6». Касание — раскрыть (пружина).
- Сверху горизонтальная лента чипов этапов «1 Старт · 2 Вчера · …» — быстрый переход.
- Касание станции — нижний лист: тема дня, число заданий, время, кнопка «Открыть» (или «сначала
  предыдущий день» / «нужен полный курс» — без повторения этого текста в каждой строке).
- При входе карта сама прокручивается к «Ты здесь».
- Доступность: карта — это список (`role=list`) с подписями «День 7, Past Simple, пройдено»;
  линия — декоративный SVG.

### 4.3 Урок (полноэкранный runner)

- Сверху: закрыть, сегментный прогресс (задание 3 из 14), без глобальной шапки.
- Карточка задания с крупными вариантами ответа (цели ≥ 56 px), выбор — пружинное нажатие.
- Снизу закреплённая кнопка «Проверить».
- Результат — нижний лист: правильно — мятный, спокойно; ошибка — тёплый нейтральный (не
  красный), правильный вариант, «Почему?» (ИИ) и «Дальше».
- Слова в тексте — пунктир; касание открывает словарь в нижнем листе: перевод, IPA, озвучка,
  примеры, «В мои слова».
- Голос: большая тактильная кнопка микрофона (мягкий объём), при записи — кольца-волны;
  аудирование — крупная кнопка «Слушать» цвета `--listen`.

### 4.4 Повтор

- Сверху кольцо «18 к повтору» и одна кнопка «Начать повтор».
- Ниже «Мои слова»: список сохранённых слов со статусом (новое / повторяю / выучено) и
  поиском; пусто — подсказка «нажимай на слова в уроках и сохраняй».
- Смешанная практика — отдельный тайл, когда доступна.

> Новая функция (отдельный PR до редизайна или вместе с D4): «В мои слова» в окне словаря.
> Сейчас слово нельзя сохранить — раздел слов всегда пустой.

### 4.5 Я (прогресс + аккаунт)

- Шапка: инициал-аватар, email или «Войти, чтобы прогресс был на всех устройствах».
- Bento-статистика: пройдено дней (кольцо x/40), серия, дни занятий, слов выучено.
- **Активность**: тепловая карта занятий по дням (как календарь привычки) — видно регулярность.
- Настройки группами: Напоминания (время в 24-часовом формате, простые формулировки), Язык,
  Тема (как в системе / светлая / тёмная), Доступ к курсу.
- Аккаунт: выйти, удалить аккаунт (с подтверждением), ссылки на политику и удаление.
- Убираем блок «Перенести старый прогресс» — переезда из старого приложения не будет.

### 4.6 Онбординг

Один экран, как сейчас, но с характером: тёмный фон с тёплым коралловым свечением, анимированная
звуковая волна (логотип «включаем голос»), три коротких тезиса, кнопка «Начать день 1» внизу.

### 4.7 Доступ к курсу

Два тайла-плана разного веса (навсегда — крупнее), «Изученное не пропадёт», без разработческих
фраз вроде «оплату подключим следующим шагом» — пока оплаты нет: «Доступ открывает
администратор. Уже есть доступ? Войти».

## 5. Движение

| Где | Что |
|---|---|
| Кнопки, тайлы, варианты | нажатие `scale(.96)`, отпускание — пружина 360 мс |
| Вкладки | View Transitions (crossfade + лёгкий сдвиг) |
| Нижние листы | выезд пружиной, затемнение фона |
| Правильный ответ | короткий «пульс» мятного кольца, без конфетти |
| Серия +1 | счётчик прокручивается вверх |
| Карта | станция «ты здесь» мягко пульсирует; раскрытие района — пружина |
| Загрузка | shimmer-скелетоны тех же форм |
| `prefers-reduced-motion` | всё движение выключено, остаются мгновенные смены |

Только `transform/opacity`; стекло — только нижняя панель, шапка при прокрутке и листы.

всё выключается при reduced motion. Замечено: часть текстов курса с родом («что делал вчера») —
поправить в контенте отдельно.

днём; касание станции — нижний лист (`src/sheet.tsx`: тема, число заданий, время, действие), системная
«Назад» закрывает лист, переход из листа не оставляет лишней записи в истории.

**D3 сделано:** урок на весь экран (`src/learn.tsx`): сверху «закрыть», сегментный прогресс (до 30 шагов,
дальше сплошная полоса) и «4/14»; этап и день; крупные варианты ответа (56 px) с состояниями «верно» (мятный)
и «ошибка» (тёплый янтарный, не красный); кнопка «Проверить/Продолжить» прижата к низу; результат —
нижняя панель с иконкой, объяснением и «Далее». Лист словаря — те же радиусы и выезд; кнопка микрофона в
разговорных заданиях — крупная, с мягким объёмом. Поведение урока и тексты кнопок не менялись.
