# UnMute — UX-аудит и план до релиза

Дата: 2026-09-30. Основа: проход владельца по редизайну D0–D6, код `apps/unmute` на `main`
после PR #285 (UX-правки и авторизация ИИ) и PR #298 (несколько курсов, тестовый A1).

Цель релиза — продукт, который выдерживает сравнение с Duolingo / Babbel / Praktika:
- понятно с первого экрана, что делать сегодня;
- каждый ответ объясняет «почему»;
- всё кликабельное выглядит кликабельным, а некликабельное — нет;
- работает в APK и в вебе, покупка курса проходит от начала до конца.

Приоритеты:
- **P0** — блокирует релиз;
- **P1** — нужно до релиза, иначе проигрываем конкурентам;
- **P2** — сразу после релиза.

(`lib/unmute-ai-trial.js`: без Plus — только пробный ИИ-разговор). Если «Почему?» должен
быть бесплатным (например, N раз в день) — это продуктовое решение, см. §4 «Решения».

## 2. Аудит экранов

### 2.1 Онбординг
- ✅ Коротко, без анкеты, сразу День 1.
- **P1** Нет выбора курса и уровня. При двух курсах (A1 и «Общий A1–B2») новичок сразу
  попадает в общий. Нужен шаг «С какого уровня начнём?» — два крупных варианта
  («С нуля» → A1, «Знаю основы» → общий курс) и ссылка «Не уверен — начнём с нуля».
- **P2** Нет цели и времени («10 минут в день»), которые конкуренты используют для
  напоминаний и мотивации. Уведомления уже есть — достаточно одного вопроса про время.

### 2.2 Сегодня
- ✅ Одно главное действие, серия, «Скажи вслух» теперь кликабельна.
- **P1** Серия и неделя активности считаются **по активному курсу**
  (`progress:course:<id>.learningDays`). После смены курса серия «обнуляется» — это ощущается
  как потеря. Решение: объединять дни занятий всех курсов (чтение всех `progress:course:*`)
  или вести отдельный общий документ дней.
- **P1** Если весь бесплатный кусок пройден, а доступа нет, «Сегодня» должна прямо показывать
  карточку «Открыть курс» с ценой, а не только повтор.
- **P2** Нет «дневной цели выполнена» (конфетти/итог дня) после урока — сильный
  мотиватор у конкурентов.

### 2.3 Маршрут (карта курса)
- ✅ Метро-карта, станции, платная граница, выбор курса (при двух и более курсах).
- **P1** Узел курса без `dayIndex` в стадии (A1: 3 дня) — стадии «метро» рассчитаны на
  40 дней общего курса. Для короткого курса нужно показывать просто линию дней без чужих
  названий стадий. Проверить на A1 после публикации (скриншоты).
- **P2** Нажатие на пройденный день — возможность «пройти ещё раз» без сброса прогресса.

### 2.4 Урок
- ✅ Теория по кнопке, объяснения у всех 452 проверяемых карточек, лист результата.
- **P1** Задания внутри **паттерн-дриллов** не имеют объяснений (в схеме у `items` нет
  `explanation`). При ошибке видно только правильный ответ. Нужно поле `explanation`
  у элемента дрилла (схема + админка + импорт) и генерация текстов при модерации.
- **P1** Тексты курса местами в мужском роде («что делал вчера»). По правилам продукта —
  без гендерных форм («что было вчера», «расскажи про вчерашний день»). Нужен проход
  по контенту (поиск по «-л вчера», «сделал», «был») и правка в админке.
- **P1** Нет индикатора «сколько осталось в уроке» в явном виде (есть полоска, но нет
  «3 из 8») — добавить подпись для доступности.
- **P2** Кнопка «Почему?» для аккаунтов без Plus — показывать замок и цену Plus сразу,
  а не после нажатия.

### 2.5 Повтор
- ✅ Отдельный старт сессии, выход, объяснения при верном ответе.
- **P1** Повтор берёт карточки **только активного курса**. Пользователь, прошедший A1 и
  переключившийся на общий курс, теряет повтор A1. Решение: очередь повтора из всех
  курсов, где есть прогресс (слова уже общие — `progress:words`).
- **P2** Итог сессии: «повторил N, из них M без ошибок» и следующий срок.

### 2.6 Я (аккаунт, прогресс, настройки)
- ✅ Кольцо курса, серия, слова, активность с пояснением, тема, язык, уведомления, курс.
- **P1** Экран «Прогресс» перегружен техническими словами: «Интервалы», «Дрилл»,
  «speed drill», «Сохранённые ответы». Переписать простым языком:
  - «Повторить сейчас»;
  - «Повторяешь: N фраз»;
  - «Точность за неделю»;
  - «Скорость ответа».
- **P1** «Мои слова» — только в «Повторе»; из «Я» до них не дойти. Добавить строку
  «Мои слова» рядом с «Прогресс».
- **P2** Удаление аккаунта — показать, что именно удалится, списком.

### 2.7 Доступ / покупка
- **P0** Реальной оплаты нет: экран говорит «доступ открывает администратор», в
  `api/billing.js` подключён только тестовый провайдер (работает лишь на memory store).
  Для релиза нужен провайдер:
  - Google Play Billing (APK);
  - App Store (iOS);
  - веб-оплата (например, ЮKassa / Stripe — решение владельца).
  Серверная часть (`packages/core/server/billing`) уже умеет адаптеры.
- **P1** На экране доступа нет цены и нет сравнения «навсегда vs Plus» с ценами — нужны
  цены из конфигурации продукта.
- **P1** Покупка должна возвращать туда, откуда пришёл (урок / карта / ИИ-разговор) и
  сразу открывать следующий день.

### 2.8 ИИ-разговор
- **P1** Без Plus пользователь не знает заранее, что разговор — пробный. Показывать
  «1 бесплатная попытка» до старта.
- **P2** Итог разговора сохранять в «Мои слова» (новые слова одним нажатием).

## 5. Решения владельца (приняты 2026-09-30)

1. **«Почему?»** — 3 бесплатных ИИ-разбора **на аккаунт за всё время** (не в день), дальше только
   Plus. Сделано: `lib/unmute-ai-trial.js` (`FREE_EXPLAIN_CALLS`), в приложении — «осталось N из 3».
2. **Оплата** — четыре провайдера: App Store, Google Play, Stripe (иностранные карты), ЮKassa
   (российские карты). **Цена задаётся для каждого курса отдельно**; по умолчанию курс навсегда
   1490 ₽ (≈ $15), Plus 399 ₽/мес (≈ $4) и 2990 ₽/год (≈ $30).
3. **Онбординг** — предварительно да: спрашивать, с чего начать. Курсов будет 5–8, поэтому экран
   выбора строится из каталога (уровень + короткое описание), а не из двух зашитых кнопок.
   «Общий английский A1–B1/B2» — текущий основной курс на 40 дней, перенесённый из English Trainer.
4. **A1** — сделать настоящим стартовым курсом: дописать до 10–14 дней.
