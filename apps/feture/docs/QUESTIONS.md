# Вопросы владельцу

Ответь коротко прямо в чате («1 — да, 2 — нет…»). Отвеченное я применяю и удаляю отсюда; правила переношу в
`AGENTS.md`, инфраструктуру — в `docs/infra/`.

2. **Проверка возраста для Великобритании и США.** Это основная аудитория, поэтому не закрываем. Законы там требуют
   «высокоэффективную» проверку для откровенного контента — наше селфи с жестом может не пройти. *Рекомендация:*
   откровенное — только проверенным; для UK и US проверка через внешнего провайдера (Didit ~$0,10 за проверку,
   500 в месяц бесплатно, или Yoti/Veriff), для остальных — наше селфи. Подключу ближе к запуску; от тебя — аккаунт
   у провайдера.

3. **«Код для входа за любого» в админке.** Сейчас через админку можно войти в любой аккаунт (так входят тестовые
   модераторы). Для живых людей это дыра. *Рекомендация:* оставить до запуска, а при переходе в `live` выключить
   автоматически. Админ-ключ ты меняешь к запуску — помню.

4. **Юрист.** Откровенный контент и оператор — гражданин РФ: это личный уголовный риск (ст. 242 УК). От ответа юриста
   зависят домен, платежи, юрлицо и документы. *Рекомендация:* одна консультация до первых реальных пользователей
   (~30–80 тыс. ₽). Найти юриста по IT/медиа можешь только ты; вопросы к нему я подготовлю.

6. **Регистрация Android-разработчика ($25, паспорт).** С 2027 года Android будет предупреждать при установке APK от
   незарегистрированного разработчика. *Рекомендация:* зарегистрировать `ru.feture.app` до конца года. Это можешь
   сделать только ты.
