# Результат → карта по выбору (W05.1)

Завершение опросника ничего не меняет в карте. На странице результата владелец
может открыть «Выбрать темы для карты», посмотреть предложения, выбрать отдельные
темы или отменить. Первоначально ничего не выбрано. Каждое добавление показано
заранее: нет отметки → «Интересно», опыт/сила не указаны, только владельцу,
без использования для знакомств. Это повод изучить тему, не вывод о желании,
согласии, роли или конкретной практике.

Предложения для шести опубликованных редакций подготовлены отдельно от scoring.
12 правил привязаны к точному JSON fingerprint определения. Изменение вопроса,
веса или интерпретации отключает старое соответствие; admin не может добавить
исполняемую формулу или автоматически переиспользовать соответствие для новой
редакции. Предлагаются только направления с достаточными ответами и уровнями
mid/high. Low/insufficient не превращаются в отказ или разрешение.

## Сохранение и конфликты

`tests.mapPreview {attemptId}` читает только своё завершённое прохождение и
возвращает до шести allowlisted предложений. `tests.mapApply` принимает UUID
операции и выбранные IDs с expectedRevision 0, без владельца/score/state/visibility.
Сервер заново определяет допустимые предложения из immutable версии и результата.

Перенос **только добавляет отсутствующие темы**. Любая существующая отметка,
включая пустую tombstone, блокирует изменение этой темы. Жёсткие/условные границы,
желание, опыт, условия и видимость владельца не перезаписываются. Чтобы изменить
существующий выбор, владелец использует обычный редактор карты.

Один owner lock и одна транзакция обеспечивают all-or-nothing: если хотя бы одна
выбранная тема появилась после preview, не меняется ни одна. Client также ждёт
подтверждённого сохранения локальной карты и разрешения конфликтов. Источник новой
отметки — `test`, immutable version ID; owner-only история показывает источник.

Receipt хранит fingerprint/attempt/count, без ответов или второго snapshot карты.
Повтор той же операции не добавляет запись/историю снова; иной payload отклоняется.
Старый retry после ручного изменения/удаления не перезаписывает выбор и не
воскрешает отметку. При потере ответа форма удерживает исходный command; можно
повторить или явно проверить текущее состояние. Удалённое прохождение не может
применить результат заново. Удаление результата само не удаляет отдельно принятые
отметки карты.
