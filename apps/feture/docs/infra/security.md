# Безопасность: от чего защищаемся

Проверено по коду 29.10.2026. Ключи, 2FA и план при утечке — [security-keys.md](security-keys.md); здесь — сценарии.
Усилие: **S** — до дня работы агента, **M** — 2–5 дней, **L** — больше недели. Срок: **①** до первых реальных
пользователей, **②** до публичного запуска, **③** потом.

## 1. Рекомендация (главное)

1. **Закрыть «вход за любого» из админки.** Админка умеет выдать код входа для любого аккаунта («Пользователи» →
   «Код для входа»). Кто знает админ-ключ, тот войдёт как любой пользователь и прочитает его чаты. Ключ сейчас слабый и
   общий (значение здесь не пишем). Мера: сменить ключ и выключить выдачу кодов, когда среда станет `live`.
2. **Второй фактор для сотрудников** (приложение-аутентификатор TOTP или passkey — вход по отпечатку или Face ID).
   Сотрудник видит чужие фото, документы и жалобы. Украли его почту — украли всё это.
3. **Уведомление о входе с нового устройства** и экран «Мои устройства» для всех.
4. **Медиа только по коротким подписанным ссылкам.** Это уже так; держать и не ослаблять.

## 3. Сценарии и меры

### Владелец и админка

| Сценарий | Мера | Усилие | Цена | Срок |
|---|---|---|---|---|
| Утёк админ-ключ → вход за любого, все данные | Новый длинный ключ, агент его не видит ([security-keys.md](security-keys.md)) | S | 0 | ① |
| То же | Выдача кода входа из админки только в `prelaunch`; в `live` выключена | S | 0 | ① |
| Захват GitHub → вредный код уходит в прод | 2FA, защита ветки `main` (только через PR с CI) | S | 0 | ① |
| Захват Vercel или Supabase → чтение всей базы | 2FA, никого лишнего в команде, оповещения о входе | S | 0 | ① |
| Админ-ключ передаётся людям | Перевести оставшиеся разделы админки на личные роли | M | 0 | ② |

### Сотрудники (модераторы, верификаторы, поддержка)

Сейчас тестовые сотрудники — адреса `@feture.test`, код им выдаёт админ ([../moderators.md](../moderators.md)).
Для живых людей это не годится.

| Сценарий | Мера | Усилие | Цена | Срок |
|---|---|---|---|---|
| Украли почту сотрудника → видит документы, селфи, жалобы | **Обязательный TOTP или passkey** для любой роли персонала | M | 0 | ① до живых модераторов |
| Сотрудник забыл выйти на чужом устройстве | Сессия персонала 12 часов, отдельно от обычной | S | 0 | ② |
| Действие от имени сотрудника | Повторный ввод второго фактора для выдачи ролей, бана, просмотра документа | M | 0 | ② |

| Сотрудник ушёл | Снять роль в тот же день; роль привязана к аккаунту, а не к почте | — | 0 | ① |

### Ссылки на медиа

Ссылка работает у любого, кто её получил, до истечения срока. Сроки уже короткие: 10 мин и 60 с. Мера: не поднимать
выше 1 часа и не кешировать подписанные ссылки в CDN дольше их срока. Усилие S, ②.

### Резервные копии

| Сценарий | Мера | Усилие | Цена | Срок |
|---|---|---|---|---|
