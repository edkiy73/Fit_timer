Проверено 29.10.2026.

## 1. Что сейчас

| Часть | Где | Комментарий |
|---|---|---|
| Сайт и API | Vercel, проект `feture-mvp`, функции в Токио (`hnd1`) | Тариф команды проверить в Vercel → Settings → Billing |

## 2. Рекомендация

1. **Перенести всё во Франкфурт до запуска**, пока данных почти нет. Из Москвы ~49 мс против ~270 мс до Токио, а
   Vercel `fra1` **дешевле** Токио.
2. **Отдельный проект Supabase для FetUre** (eu-central-1): взрослые данные не рядом с FitTimer. Регион у проекта не
   меняется — только новый проект и перенос.
3. **Медиа — на Bunny.net** (хранилище во Франкфурте + CDN). Bunny **письменно разрешает** легальный взрослый контент.
   Это компания из ЕС (Словения) и не Cloudflare, а Cloudflare в РФ с 06.2025 замедляют.
   Запасной вариант — R2: код готов, взрослое не запрещено, но в РФ работает нестабильно.
4. **Через Vercel откровенные медиа не пропускать никогда.** Правила Vercel запрещают «obscene, graphic» контент и
   хостинг медиа для горячих ссылок. Vercel отдаёт только сайт и JSON. На случай претензии держать план переезда
   API (например, Hetzner или Fly.io в ЕС; проверить).
5. **Vercel Hobby — пока нет платежей и рекламы.** Hobby разрешён только для некоммерческого использования. С первым
   платежом — Pro, $20/мес.

## 5. Что делает владелец

1. Supabase → New project → регион **Central EU (Frankfurt)**, имя `feture`. Пароль базы хранить в менеджере паролей.
2. Bunny.net → регистрация. Оплата картой не из РФ. Создать Storage Zone (Frankfurt) и Pull Zone. Ключи вставить в
   Vercel → Environment Variables (агент скажет имена).
3. Когда начнутся платежи — Vercel → Upgrade to Pro.
4. Позже — включить PITR в Supabase → Add-ons.

## 6. Что делает агент

- Переносит схему и данные, ставит `fra1`, обновляет адрес задач в Vault, проверяет вход, ленту, медиа, push. Схема в
  FitT удаляется после подтверждения.
- Пишет адаптер Bunny по образцу R2 (подписанные ссылки, только одобренное); подключает Sentry и UptimeRobot.

## 7. Риски

Правила Vercel и Supabase сформулированы широко и толкуются на их усмотрение — медиа у них не держим (к тому же
Supabase Storage дорогой: трафик $0,09/ГБ, ресайз $5 за 1000). «Белые списки» мобильного интернета в РФ (Москва, с
03.2026) делают сайт 18+ недоступным без VPN при любом хостинге. Работает ли Bunny из РФ — проверить тестом.

## 8. Переносимость по коду (31.10.2026)

Это проверка реализации, не завершённый перенос. Production пока использует прежние провайдеры.

| Часть | Что уже отделено | Что осталось перед переключением |
|---|---|---|
| UI | React/Vite, статический `dist`, без Next.js | CDN/HTTPS, SPA fallback, кэш, `/kit`, Android deep links и API origin |
| API | Node `(req,res)` handlers; общий `packages/core/server/node-host.js` | Композиция всех API FetUre на Node, `/api/config` rewrite, reverse proxy, CORS и проверка маршрутов |
| Доменная БД | `FETURE_DATABASE_URL`, прямой `postgres`, схема `feture` | Отдельный PostgreSQL, роли/расширения/миграции, сверка данных и тест восстановления |
| Вход и старая админка | AppBase auth, а не Supabase Auth | Core `store.js` при `APPBASE_STORE=supabase` вызывает `kv_exec` через PostgREST; legacy `lib/feture` и `api/catalog.js` тоже используют Supabase REST. Одной замены `FETURE_DATABASE_URL` недостаточно |
| Realtime | Сигналы отделены в `server/realtime.mjs` | Supabase Broadcast, клиентский транспорт и проверка домена `.supabase.co` в API; нужен отдельный транспорт либо проверенный self-hosted Supabase |
| Очередь | `outbox` и `runJobs` на PostgreSQL/Node | Сейчас запуск через pg_cron + pg_net + Vault. Нужен scheduler с прежней защитой jobs secret |
| Медиа | Интерфейсы `Storage`/`Delivery`, ключи вместо URL в БД | Адаптер Bunny, закрытый origin, токены, range/206, CORS WebView, TTL и отзыв доступа; перенос с проверкой SHA-256 |

**R2 пока нельзя просто включить:** `workers/media/index.mjs` разрешает только `thumb/card/full/blur`, а API
выдаёт и `file` для видео/голоса. Worker ресайзит `o/<id>` как изображение, в том числе для видеопостера,
а R2-композиция отключает серверный renderer. Нужны выдача готовых вариантов и byte ranges либо отдельный video
pipeline. Viewer id в токене сам по себе не проверяет личность предъявителя: эта привязка требует проверки на edge.

**Первый перенос — медиа на Bunny** по рекомендации §2: сохранить ключи, карантин, модерацию и серверные разрешения.
Готовые WebP можно перенести без покупки Optimizer. Bunny S3 существует, но на дату проверки находится в public
preview и включается при создании новой зоны. Проверить presigned PUT/HEAD/GET/DELETE на конкретной зоне;
постоянный AccessKey обычного HTTP Storage API никогда не выдавать клиенту.
Доставка — закрытая Pull Zone с Token Authentication; browser TTL настраивается отдельно на CDN: S3 metadata
Cache-Control сейчас не переносится в CDN-ответы. Карантин `u/` через CDN недоступен.

До переключения: копирование оригиналов/вариантов/карантина, сверка числа и хэшей; перенос новых записей за время
копирования либо короткая остановка загрузок; ожидание старых upload URL и завершения сканирования. Проверить
приватные/одноразовые/отозванные доступы, перемотку, удаление/блокировку и выход. Старое хранилище сохранить
для отката, удалить после сверки и проверки. Одна смена env не переносит объекты старого бакета.

**Vercel и БД — отдельный этап.** Варианты: Node + PostgreSQL/PostgREST + сигналы и scheduler (меньше сервисов,
больше работы над адаптерами), либо self-hosted Supabase (выше совместимость, но эксплуатация всего стека).
Для полного self-hosted Supabase документация указывает минимум 4 ГБ RAM/2 CPU, рекомендует 8 ГБ+/4 CPU+.
Обновления, бэкапы, мониторинг и восстановление становятся нашей ответственностью. Конкретный платный хостинг
и регион выбирает владелец; эта проверка ничего не покупает и не переключает production.

**Оптимизация текущего приложения:** видео/голос подключают файл при воспроизведении; за экраном/в скрытой
вкладке пауза; размонтирование освобождает плеер. Лента берёт постер `card`, просмотрщик — текущую и соседние
фотографии. Это уменьшает будущий расход, не списывает уже учтённый. Сроки ссылок сохранены: обычные 600 с,
одноразовые картинки 60 с; для видео отдельная нижняя граница 300 с и ограничение grant. Повторное использование
URL уже есть в `delivery.mjs` (только тёплый процесс), сжатие — в `kit/video-edit.ts` / `video-size.ts`
(до 1280 px, примерно 0,8–3 Мбит/с). Годовой кэш и суточные приватные ссылки не включаем.
