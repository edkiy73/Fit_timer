# Магазины приложений и Android-верификация

Проверено 29.10.2026. Что есть сейчас: APK ставится из GitHub (`feture-latest`), подписан своим ключом FetUre.
Обновление обязательное и выпускается из админки. Push через FCM работает. Сборка AAB для Google Play уже делается в
том же запуске (`docs/android-release.md`).

## 1. Рекомендация

**Порядок действий:**
1. **Сейчас** — продолжать раздавать APK с сайта и GitHub. До 2027 года это работает везде.
2. **До конца 2026** — зарегистрироваться разработчиком в Google ($25) и зарегистрировать пакет `ru.feture.app` с
   текущим ключом подписи. Это нужно не ради Google Play, а чтобы наш APK продолжил ставиться в 2027 году.
3. **Google Play — позже, отдельной «чистой» сборкой**: без откровенного контента внутри.
4. **iOS — позже**, тоже «чистая» сборка; откровенное включается только на сайте.
5. **RuStore — не использовать.** Правила запрещают «садизм» и «ЛГБТ-пропаганду», требуют регистрации в реестре ОРИ
   и хранения данных в РФ.

## 2. Верификация Android-разработчиков (касается нашего APK!)

- **С 30.09.2026** требование действует в Бразилии, Индонезии, Сингапуре и Таиланде, но **только для установок из
  магазинов** (Play, Galaxy Store, Xiaomi и др.). Цитата Google: если пользователи ставят APK напрямую, требование
  «won't apply to your app yet».
- **2027 — по всему миру, для всех APK** на сертифицированных устройствах. Точной даты нет.
- **APK неверифицированного разработчика** с 2027 года ставится только через «расширенный режим» с перезагрузкой и
  **24 часами ожидания**. Для обычного человека это конец установок.
- **Регистрация:** $25 один раз (аккаунт Play Console покрывает и APK вне Play); паспорт, подтверждение адреса, email,
  телефон. Пакет регистрируется по имени и отпечатку SHA-256 ключа, владение подтверждает подписанный тестовый APK.
  **Содержимое приложения не проверяется**, 18+ не мешает.
- **Под вопросом:** пустят ли резидента РФ; российская карта почти наверняка не пройдёт — платить картой не из РФ.

## 3. Стоимость

| Что | Цена |

## 4. Что делает владелец

1. Открыть play.google.com/console (лучше сразу Play Console, тип «личный»). Оплатить $25 картой не из РФ, пройти
   проверку личности.
2. В разделе верификации Android указать пакет `ru.feture.app`. Отпечаток ключа агент возьмёт из итогов сборки.
   Загрузить подписанный тестовый APK, который подготовит агент.
3. Для Google Play: найти **12 тестировщиков**, которые **14 дней подряд** держат закрытую тестовую сборку. Это
   обязательное правило для новых личных аккаунтов.
4. Для iOS: найти способ оплатить $99 картой не из РФ. Проверить, принимает ли Apple владельца с адресом на Бали.

## 5. Что делает агент

- Готовит тестовый APK для подтверждения владения пакетом.
- Делает «магазинную сборку»: откровенное скрыто по умолчанию и включается только на сайте.
- Проверяет обязательное для Play и Apple: жалобы, блокировка в чатах, принятие правил до первой публикации, страница
  CSAE-стандартов, контакт по детской безопасности.
- Для iOS: подключает APNs (код в Core готов: `APNS_KEY_ID`, `APNS_TEAM_ID`, `APNS_PRIVATE_KEY`) и Declared Age Range API.

## 6. Правила магазинов коротко

| | Google Play | Apple | RuStore |
|---|---|---|---|
| Порнография | Запрещена, как и «позы обнажённых» | Запрещена (1.1.4), включая hookup-приложения | Запрещена |
| Откровенный UGC | Только «случайный»: скрыт фильтром по умолчанию + возрастной экран | Только «incidental», скрыт и включается **на сайте** (1.2) | Эротика 18+ без порно, **без садизма** |
| Модерация | Жалобы, блокировка, правила — обязательно | Фильтр, жалобы, блок, контакты | Правила, жалобы, блок |
| Знакомства | Блокировать несовершеннолетних | Рейтинг 18+ | — |
| Оплата Premium | Play Billing; выплаты на счета в РФ остановлены с 12.2024 | Только IAP (кроме витрины США) | Своя оплата или задекларированная внешняя |

Apple с 24.02.2026 отдаёт приложения 18+ в Австралии, Бразилии, Сингапуре только подтверждённым взрослым; в Юте,
Луизиане и Техасе — законы о возрасте в магазинах. Нам нужны честный рейтинг 18+ и своя проверка возраста.

Feeld есть в App Store (18+): нагота в публичных фото запрещена, в чатах размывается. У FetLife приложения в магазинах нет.

## 7. Риски

Потеря ключа подписи = пакет не обновить ([security-keys.md](security-keys.md)). Без регистрации до 2027 года
установки APK остановятся. Google может отказать резиденту РФ — тогда нужна компания и D-U-N-S. «Чистая» сборка, где
откровенное тайно включается внутри, = бан аккаунта разработчика.
