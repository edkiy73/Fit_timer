# Юридические документы и главная развилка

Проверено 29.10.2026. Это не юридическое заключение: перед запуском нужен юрист.

## 1. Рекомендация

**Главное решение: FetUre — зарубежный сервис, который не «направлен на Россию».** Русский язык допустим. Не нужны
домен .ru, цены в рублях в интерфейсе, реклама в российских сетях и российский хостинг.

Почему:
- **Ст. 242 УК РФ.** Порнография через интернет — преступление, даже взрослая и легальная; «распространением»
  признают и фото в личке (2025: 2,5 года условно). Барьер 18+ не освобождает, а оператору-гражданину РФ ст. 12 УК
  может вменить и деяния за границей (оба пункта проверить у юриста).
- **478-ФЗ.** Запрещает «пропаганду нетрадиционных сексуальных отношений и (или) предпочтений». Под «предпочтения»
  можно подвести kink. ЛГБТ-«движение» признано экстремистским, поэтому ЛГБТ-контент грозит ст. 282.2 УК.
- **Требования к сервисам «для России»** (локализация, вход по российскому номеру, РКН, ОРИ) с откровенным контентом
  несовместимы ([personal-data-law.md](personal-data-law.md)).

Вывод: блокировка РКН вероятна при любом варианте (пример — Hornet, 2023). Пользователи из РФ будут заходить через
VPN. Наша задача — снизить личный риск владельца, а не избежать блокировки.

### Решающее правило после юриста

| Ответ юриста | Что делаем |
|---|---|
| Риск по 242 УК для владельца реален | Оператор — иностранная компания. Откровенные медиа видны только после проверки возраста. Владелец публично не связан с сервисом |
| Риск приемлем при ограничениях | Откровенные медиа не показываются пользователям с IP РФ (Vercel определяет страну по IP, агент добавит проверку). Остальное доступно |
| Владелец хочет работать «на Россию» легально | Убрать откровенный контент целиком, хостинг в РФ, вход по телефону РФ. Это другой продукт |

## 3. Что делает владелец

1. Найти юриста по IT/медиа (242 УК, 152-ФЗ), задать три вопроса из таблицы. Спросить и про Индонезию (закон
   44/2008 о порнографии, жизнь на Бали) — мы это не проверяли.
2. Выбрать, на кого оформлять сервис (решающее правило — в [payments.md](payments.md)).
3. Оформить представителя в ЕС (Prighter, договор онлайн). Предварительно спросить, работают ли они с 18+.
4. Прочитать и утвердить финальные тексты в админке → «Документы и согласия».

## 4. Что делает агент

- Пишет черновики RU и EN и публикует новой версией через админку (повторное согласие уже есть).
- Добавляет страницу «Контакты и правовая информация»: оператор, адрес, email для властей, представитель в ЕС.
- Проверяет, что cookie только технические, — тогда баннер не нужен.

## 5. Минимальный набор документов

Что уже есть: четыре обязательных документа RU v1 опубликованы в FitT. Это условия, конфиденциальность, правила
сообщества и согласие 18+. Тексты стартовые, не юридически вычитанные. Отказ от согласия и повтор при новой версии
реализованы (`docs/documents-consent.md`). Уведомления DSA уже работают: форма без аккаунта, приоритет CSAM, ответ
заявителю с причиной, цифры прозрачности для персонала (`server/commands/dsa.mjs`).

| Документ | Нужно | Статус |
|---|---|---|
| Пользовательские условия (DSA ст. 14) | Да | v1 RU, нужен EN и юрист |
| Политика конфиденциальности (GDPR, 152-ФЗ ст. 18.1) | Да | v1 RU, нужны EN и список обработчиков |
| Правила сообщества | Да | v1 RU |
| Согласие 18+ и на «чувствительные» поля (интим, ориентация) | Да, отдельной галочкой | v1 18+; отдельного согласия на kink-поля нет — добавить |
| Оферта на Premium (возвраты, автопродление) | Перед платежами | Нет |
| Контактная точка для властей и пользователей (DSA ст. 11–12) | Да | Добавить страницу |
| Представитель в ЕС (DSA ст. 13) | Да | Нет |
| Уведомление о нарушении (ст. 16) и решение автору (ст. 17) | Да; в базу ЕС слать не обязаны | Есть |
| Отчёт о прозрачности (ст. 15, 24) | Малые освобождены; по запросу сообщить число пользователей | Цифры уже считаются |
| CSAE-стандарты (требование Google Play) | Да, публичная страница | Нет |
| Impressum (Германия) | Если ориентируемся на Германию — да | Закрыть страницей «Контакты» |
| Cookie-баннер | Нет, если cookie только технические | Проверить |

Освобождение «micro/small» (меньше 50 человек и не больше €10 млн оборота) снимает с FetUre ст. 20–28 DSA: внутреннюю
систему жалоб, базу решений, ст. 28. Ст. 11–18 остаются.

## 6. Риски

Без юриста владелец не знает свой личный уголовный риск. В «Контактах» должен стоять реальный оператор. Российские
документы (политика ПДн, оферта ИП) — сигнал «направлен на РФ», публиковать только по решению юриста.
