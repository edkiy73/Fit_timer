## Обязательное новое решение

- Пять постоянных разделов: **Лента / Люди / Сообщества / Чаты / Я**. Это заменяет схемы 4+условная пятая и Моя карта/Темы/Общение/Я/Знакомства.
- Лента: Основная / Подписки / **События**. События полноценны: онлайн/офлайн, время и зона, язык, заявки, RSVP, приватность, organizer, внешние ссылки и отмена. События не шестая кнопка дока.
- Я: Моя карта / Изучить / Дневник, понятные входы в профиль, доступы, пары, сохранённое и свои события. Уведомления и настройки справа в шапке.
- **RU / EN** обязательны для каждого экрана, состояния, письма, push, ошибки и доступности. Язык интерфейса, контента, события и часовой пояс независимы. Light / Dark / System.
- Социальный публичный профиль существует независимо от подбора. Переходы из поста и поиск по нику сохраняются при выключенных знакомствах. Социальный поиск не имеет кандидатских фильтров. Просмотр кандидатской подборки требует собственного явного opt-in; выключенный участник не появляется в ней.
- Личная симпатия из социального профиля возможна вне подбора; только взаимная симпатия открывает личный чат. Подписка, лайк поста, роль организатора, Premium и выдача приватного доступа чат не открывают. Социальная симпатия не включает discovery автоматически. Новые UI-only утверждения не меняют server ACL сами.
- Расширенные поля и материалы по отдельному запросу, точному scope, сроку и отзыву. Отправленные/ожидающие и действующие доступы в одном центре. Premium увеличивает квоту, не покупает согласие. Базовая приватность и отзыв бесплатны.
- Фото не обязательно для регистрации и первого опросника; оформление профиля отдельно. Проверка возраста — фактический отдельный процесс, не публичное фото или галочка.

Следующий результат: все макеты и кликабельные десять путей в обеих темах и языках, с четырьмя реальными компоновками. Не объявлять отдельный CSS PR закрытым дизайном. Дальнейшие Issues должны ссылаться на сценарий, экран, вход, действие, реальный результат, права, состояния и проверку. Старую очередь сопоставить с новым документом; сохранённые защитные доменные требования не отменять.
