## Что Claude должен доработать

1. Открыть новый интерфейс и проверить Лента → профиль → Баночки → объяснение совпадения; Люди → симпатия → кружок в Чатах → диалог; Я → карта → опрос → результат; Сообщества → правила/участники; События → карточка → участие.
2. Улучшить современную визуальную иерархию, пропорции фото, плотность, карточки и окна на 320/390/768/1024/1440 px. Не возвращать универсальные одинаковые списки для разных задач.
3. Проверить вторичные экраны, все окна и возвраты; убрать повторы заголовков, неверные родительские разделы и несогласованные стили. Исправлять целыми пользовательскими путями.
4. Сохранить все счётчики, профильные чипы, баночки, взаимность в Чатах, RU/EN, обе темы и reduced motion. Новая структура важнее старого HTML.
5. Честно отделять визуальные действия от реальных операций: Core вход настоящий; изменения анкет/баночек/сообщений/членства — память макета. Domain API, grants, квоты, доставка, RSVP, медиа и платежи требуют отдельного подключения. Не менять SQL, серверные права или допуски ради красивого макета.

## Порядок работы

Прочитать `AGENTS.md`, `apps/feture/AGENTS.md`, `docs/design-reference/PRODUCT-SPEC-START.md` и этот handoff, затем только нужные компоненты. Эпики #908/#1015/#869 остаются открыты. Проверки: `npm run typecheck`, `npm run test:smoke`, `npm run build` в `apps/feture`; для затронутых пользовательских путей браузерная проверка и независимое ревью. Не объявлять результат готовым к выпуску по одной сборке.

Интерфейс требует обычного входа в аккаунт. Эта публичная инструкция не даёт доступ к чужим данным и не обходит возрастные/серверные проверки. Если сессии нет, изучить исходники новых компонентов и войти через нормальную форму; не переходить на старый интерфейс как замену.
