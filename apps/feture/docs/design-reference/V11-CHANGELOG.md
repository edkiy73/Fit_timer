# FetUre V11 — что изменено

V11 — копия V10 (main @ 3085b6d0, после #1196 и #1197) с исправлениями по UX-аудиту [`V10-UX-AUDIT.md`](V10-UX-AUDIT.md).
V10 остаётся замороженной: `public/prototype-v10.html`. Новая версия: `public/prototype-v11.html`.

Решения владельца (20.10.2026):
- тесты на паузе — упоминания тестов убраны из интерфейса;
- пара — у каждого свой аккаунт, профили связываются приглашением, второму партнёру короткий вход;
- вкладка «Я» → «Профиль» (у пары — «Профили»);
- отказ в доступе показывается мягко, но однозначно («решили не открывать»); повторный запрос — не раньше чем через 30 дней.

Номера задач (UX-NN) — из аудита.

## 20.10.2026 — исправления по UX-аудиту

### Онбординг
- **UX-01 · тесты.** Шаг «Первый тест» убран (он показывал интересы). В шторке «Создать», композере, ленте и знакомствах «результат теста» заменён на «интересы»: вложение «Интересы», тип «С интересами», «Добавить интересы» вместо «Пройти тест». Плитка «Тесты» в профиле осталась со «Скоро».

## 20.10.2026 — правки по скриншотам владельца

1. **Приглашение в пару.** «У партнёра ещё нет аккаунта? Отправь ссылку» выглядело сломанной ссылкой (иконка слева, текст по центру в две строки). Теперь: разделитель «или» → кнопка «Скопировать ссылку для партнёра» → пояснение под ней.
2. **Раздел «Профиль».** Блок пересобран: карточка личности (аватар, ник, город, «Изменить профиль»), ниже один список обычных строк — «Следующий шаг» и «Профиль пары». Раньше внутри одной карточки лежали три разных стиля вплотную.
3. **Чаты.** «Архив» — иконка в шапке рядом с поиском и уведомлениями, а не ссылка под списком.
4. **Порядок ответов («Интересные / Новые»).** Тот же переключатель на всю ширину, что и остальные табы.
5. **Подсказки.** В «Новом обсуждении» — блок «Кто увидит» с отступом и понятным текстом («Только участники сообщества» / «Все, кто зайдёт в сообщество, — и участники, и гости»). В чужом обсуждении без членства — блок «Отвечать могут участники» + «К сообществу» вместо приклеенной серой строки.
6. **Список участников.** Постраничный: «Показать ещё · Показано N из 1285» дописывает по 20 (в прототипе — демо-строки без публичных профилей).
7. **Рамки плиток «Добавить» (фото/видео в редакторе и в приватной части)** больше не обрезаются с одной стороны: сетка редактора не клиппит содержимое.

## 20.10.2026 — проход по отступам на всех экранах

- **Причина.** В контейнерах `.wrap` / `.auth-wrap` / шторках соседние обычные блоки (абзац, примечание, кнопки) не имели вертикального ритма: «Связь остановлена» склеивала счётчик с кнопкой, две кнопки друг с другом, а текстовая кнопка «К личному аккаунту» прижималась влево.
- **Правило.** Один ритм для простых стопок (нулевая специфичность, явные `.mt8` / `.mb12` по-прежнему главнее): кнопка — кнопка 10 px; абзац / примечание / карточка → кнопка 14 px; кнопка → абзац 12 px; заголовок → абзац 8 px; абзац — абзац 10 px; текстовая кнопка по центру. Класс `.mb12` (использовался в разметке, но не был определён) теперь существует.
- **Точечно:** чипы фильтра → карточка (уведомления), «Тесты — Скоро» (кнопка под заголовком), примечание → пустое состояние, пара чекбоксов.
- **Как проверял.** Скрипт обходит все 77 экранов QA + состояния (пара, разрыв пары, шторки `!…`) и ищет соседние блоки без зазора (кнопка–кнопка, текст–кнопка, карточка–карточка). До правки находок было 13 уникальных, после — осталось 4 намеренных (счётчик «0 / 500» под полем 4 px, строка «Демо» внутри блока с собственной линией, пара чекбоксов с собственными отступами, текст ответа в карточке заявки). Экраны Q07, Q01, Q06, A04, A05, F07, E-группа, K-группа просмотрены глазами на 390 px.

## 21.10.2026 — правки владельца, раунд 3

1. **Табы в профиле** («Публикации / События / Активность / Сообщества») — без счётчиков; таб без содержимого не показывается (как и раньше), у единственного таба заголовок тоже без числа.
2–3. **Порядок ответов** — не табы, а выбор сортировки: «Сортировка · Сначала интересные ⌄» / «Сначала новые» (общий компонент с остальными выпадающими списками).
4. **«Мало данных»** на карточке знакомств убрано: плашка с числом общих интересов показывается только когда есть что показать.
5. **Фильтры ленты:** убраны «Публикации — Все / Только подписки» (это уже табы «Для тебя / Подписки») и переключатель «Показывать события» — события в ленте показываются всегда.
6–7. **«Подписки» как лента активности** (по образцу «Отслеживаемое» на FetLife): публикации тех, на кого ты подписан, и их публичная активность — «нравится публикация», «идёт на событие», «в сообществе», «теперь следит за …». Над лентой список «Что показывать»: Вся активность / Публикации / Фото и видео / Опросы / Лайки / События / Сообщества / Подписки. Чья активность видна, решает сам человек (Настройки → Приватность → Активность: все / подписчики / никто) — это уже работало в профиле, лента берёт те же данные и те же правила. Формулировки без рода («нравится», «идёт», «теперь следит»). Темовые фильтры действуют только на публикации и прячут карточки активности. Дальше (не сделано): размер медиа «крупно / мелко», фильтр «Группы» отдельно, лента событий отдельной вкладкой.
8. **Редактор публикации:** значок профиля слева от «Кто увидит» показывался даже без пары. Теперь выбор автора есть только у пары — одинаково при создании и редактировании; без пары одна строка «Кто увидит».
9. **Аудитория «Кому открыт доступ»** → «Приватная часть · N» (короткая подпись; без числа, если доступ никому не открыт).

- **Шапка чата:** плашки показываются, только если несут смысл. Нет «Пока мало общего контекста» и нет «Приватная часть закрыта» у человека, у которого приватной части нет; если плашек нет, строки нет совсем.

- **Фильтры:** убраны подписи «Действует только для подписок.» (фильтры ленты) и «С такими фильтрами пока ничего нет. Можно применить их или изменить выбор.» (внизу всех окон фильтров; о нуле результатов говорит надпись на кнопке «Применить»).

- **Аудитория поста:** «Кому открыта приватная часть · N» была слишком длинной в выпадающем списке — теперь «Приватная часть · N» (без числа, если доступ никому не открыт).

- **«Что показывать» в «Подписках»** переехало с ленты в окно фильтров: первая секция с чипами «Публикации / Лайки / События / Сообщества / Подписки» (можно несколько, пусто = всё). Выбранное видно активными чипами над лентой и в счётчике «Фильтры». Строка «Что показывать» над лентой убрана.

## 21.10.2026 — склеенная активность в «Подписках»

- **Склейка.** Два и больше однотипных действия одного человека за один день собираются в одну карточку: «Maya: нравится 3 публикации» + ряд превью (до 5; текстовая публикация — плитка с сердцем). Так же для подписок («теперь следит за 3 людьми» — аватары), событий («в планах 2 события» — список) и сообществ («в 2 сообществах»). Одно действие остаётся обычной карточкой.
- **«+N».** Если действий больше пяти, последняя плитка «+N» раскрывает полный список прямо в ленте (лента удлиняется), «Свернуть» возвращает. У событий и сообществ — «Ещё N».
- **«⋯» на карточке:** «Открыть профиль» и «Не показывать активность» (публикации человека остаются, пропадают лайки, события, подписки; есть «Вернуть»).
- **Настройка «Показывать мои лайки подписчикам»** (Настройки → Приватность профиля), по умолчанию включена. Без неё лайки не попадают в ленту подписчиков и в активность профиля. В демо лайки скрывает Kai.
- В демо-данных у части людей лайки идут «пачкой» за последние часы, чтобы склейка была видна.

- **Лайк поста, где есть всё:** превью — первое медиа (у видео — постер), в углу счётчик медиа («видео 4»), над плиткой маленькие метки: красная — опрос, фиолетовая — интересы. В развёрнутом списке состав словами: «Sofi · видео · 3 фото · опрос · интересы · 24 мин назад». Приоритет превью: видео/фото → опрос → интересы → текст.

- **Вкладки сообщества** («Обсуждения / События / Участники / Правила») — без счётчиков и на всю ширину: названия больше не обрезаются («Обсу…»).

- **Склейка по паузе, а не по календарному дню:** действия одного вида одного человека без паузы дольше 6 часов — одна «пачка». Раньше пачка лайков рвалась в полночь (CI в 00:22 UTC показал это, исправлено в этом же проходе).

- **Ряд превью в склеенной активности** ведёт себя как ряд чипов у кнопки «Фильтры»: справа закреплена кнопка «+N» (N — сколько плиток ещё скрыто справа, число уменьшается при прокрутке; в конце — стрелка «раскрыть»), плитки и аватары прокручиваются вбок и уходят под неё с затуханием; затухание слева появляется, только когда ряд уже прокручен. Кнопка раскрывает полный список. Кнопка «⋯» на карточке больше не уезжает за край экрана.
- **Плитки превью — чистые квадраты:** фото больше не «стопка» со сдвигом (она вылезала за подложку), метки опроса/интересов/видео лежат внутри верхнего правого угла и не обрезаются. Счётчик честный: у поста «3 фото + видео» — «▣ 3» и метка видео, а не «видео 4».
- **Видео видно сразу:** на обложке видео в посте (и на плитке превью в активности) по центру круглая кнопка «▶», длительность остаётся в углу.
- **Метки на превью — одна система:** снизу слева одна тёмная капсула называет медиа поста — «▣ 3» (фото), «🎥 0:06» (одно видео), «🎥 2» (несколько видео), «▣ 3 🎥 1» (вперемешку); одно фото — без капсулы. Сверху справа круглые метки того же тона — опрос и интересы. Одинаково на плитках активности, в развёрнутом списке и в ленте.
- **Play один и тот же везде:** треугольник по оптическому центру круга; в полноэкранном плеере вместо браузерной кнопки — тот же круглый play (полоса управления браузера для перемотки осталась). В ячейке «+N» сетки play и длительность не рисуются.
- **Открытая вкладка переживает обновление страницы** — везде: вкладка экрана (sub / tab / kind / t / k) пишется в адрес (`#F01;sub=following`) и восстанавливается при загрузке. Данные форм в адрес не попадают.
- **Один компонент превью-квадрата (`.pth`)** для ряда активности, развёрнутого списка и активности в профиле (события, сообщества и люди — в той же рамке): одинаковый размер, рамка, капсула и метки. На превью нет длительности видео; число показывается, только если больше одного: «▣ 3», «🎥», «🎥 2», «▣ 3 🎥». Пост без медиа — квадрат «Опрос» / «Интересы» или фрагмент текста везде одинаково (карандаш в списке убран). Длительность осталась только на самом видео в ленте.
- **Капсула медиа — по одному правилу:** у каждого вида есть иконка (одно фото «▣», одно видео «🎥», «▣ 3», «🎥 2»); если в посте и фото, и видео — пишутся оба числа («▣ 3 🎥 1», «▣ 1 🎥 1»). Шрифт капсулы не жирный.
- **Капсула медиа фиксированной высоты:** иконка без цифры стоит на одном уровне с иконками рядом с цифрами (раньше капсула без текста была ниже по высоте и иконка «проваливалась» вниз).
- **Одна карточка сущности (`.ecard` / `entityCard()`)** для превью поста, человека, события и сообщества — в активности ленты (одиночная и развёрнутая) и в активности профиля. Раньше было три разных вёрстки (карточка ленты, строка списка профиля, плитка) с разными размерами шрифтов и иконок. Теперь: квадрат (`.pth`) · [кикер «Нравится / Идёт на событие…» — только в профиле] · заголовок 14.5/600 · при необходимости строка · одна строка меты с иконками 13px (12px текст).
- **Человек в карточке** — имя, возраст, значки (подтверждён, премиум), пол и ориентация, город с иконкой и «в сети» / когда был. Пост — автор и состав, ♥ лайки и 💬 комментарии (нули скрыты). Событие — дата, формат/город. Сообщество — число участников. В профиле дополнительно «когда».
