# FetUre V4 — связанная реализация дизайна

Источник: [MASTER-PRODUCT-SPEC-V4](MASTER-PRODUCT-SPEC-V4.md). **127 экранов, 24 общих окна, 10 пользовательских путей J01–J10.** Это начальный связанный комплект, не окончательная визуальная приёмка и не подтверждение live-функций.

## Где открыть

После обычного Core входа: `/#/design/F01`. В аккаунте — «Открыть новый интерфейс». Это отдельный маршрут существующего React/AppBase приложения; старые рабочие доменные маршруты сохраняются до приёмки V4. Код дизайна загружается отдельным chunk.

Пять постоянных разделов: Лента / Люди / Сообщества / Чаты / Я. События в Ленте; Моя карта / Изучить / Дневник внутри Я. Phone: glass dock; tablet/fold: rail; desktop: sidebar, рабочая зона и дополнительная колонка. RU/EN; Light/Dark/System. На телефоне подборка имеет внутренний scroll и постоянно доступные кнопки выбора.

## Один список подключения

Кнопка с часами в шапке открывает общий список неподключённых функций, последнее действие и каталог всех экранов/24 окон. Не создавать отдельные технические плашки по всем экранам. Оплата, проверка возраста, отправка приватных материалов и реальная взаимность не выдаются за успешный серверный результат.

`fixtures.ts` — исключительно предварительные иллюстративные профили/посты/события/группы; они не являются live seed ID. Изменения — память React, сбрасываемая при перезагрузке/смене полной Core сессии. Нет domain requests, SQL/Storage/ACL изменений или новых localStorage документов. Язык/тема используют существующий AppBase. Выбранные файлы не загружаются и их байты не сохраняются. Перед реальными пользователями убрать/исключить фикстуры.

Редактор → аудитория/материал/предпросмотр сохраняет ввод. Выход из незавершённого сценария спрашивает подтверждение. Переписка Maya не появляется у Alex/в парном диалоге. Профиль из Ленты сохраняет родительский раздел. Числовой group query проверен на целочисленность и диапазон. Неизвестный экран направляется в S05. Возврат после входа допускает лишь внутренний `/design/XX00` без query/внешнего URL.
