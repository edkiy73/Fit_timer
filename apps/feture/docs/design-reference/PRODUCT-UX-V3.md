# FetUre — пересборка UX V3: актуальный контракт

Решение владельца 13.10.2026, **уточнение 02:53**. Заменяет прежние IA V2 и начальную V3 с гостевым режимом/условной пятой вкладкой. Полная очередь и сценарии: [USER-JOURNEYS-V3.md](USER-JOURNEYS-V3.md). Визуальный ориентир — Claude HTML; серверные privacy/age/consent правила остаются обязательными.

## Аккаунт до приложения

Приветствие → «Создать аккаунт» / «Войти» → настоящий email/OTP → серверный минимальный профиль → Моя карта. Нет тестового/гостевого входа, вопроса «зачем ты здесь», локальной карты, гостевого импорта и обязательного теста. Не создавать отдельный auth; Core канонический. Ошибка создания профиля требует явного восстановления, OTP не доказывает успешного создания domain profile.

Обязательная регистрация не означает обязательную возрастную проверку первым шагом. Минимальный ник/аккаунт и разрешённая оболочка отделяются от sensitive profile fields. Для ограниченного действия — контекстный 18+/consent gate. Не снять server guard с чувствительного RPC ради удобства; minimum provisioning требует отдельного server DTO/контракта и проверки.

## Постоянная навигация

| Раздел | Назначение |
|---|---|
| Моя карта `/world` | Только мои интересы, отношение, опыт, границы, результаты и дневник. Домашний раздел после входа. |
| Темы `/explore` | Общий редакторский каталог: определения, материалы, вопросы. Отсюда добавляют личную отметку в карту. |
| Общение `/community` | Лента, группы, события и сообщения внутри одного раздела. |
| Я `/account` | Внешний профиль/предпросмотр, видимость, доступ, настройки и безопасность. |
| Знакомства `/dating` | Вкладка есть всегда. До opt-in — экран предложения включить; после server opt-in — подборка. |

Ровно пять пунктов на phone/tablet/desktop, без отдельной Главной. Пауза знакомств не удаляет вкладку. Один ProductLayout, безопасные compact labels/доступные имена, safe area, no overflow 320px. Desktop — полноценная боковая навигация. Переименование подписей не меняет существующие URL.

## Server-only

Все пользовательские данные и prefs — на сервере. Нет localStorage/IndexedDB/Capacitor storage для карты/ответов/дневника/drafts/opt-in, durable offline очереди и миграции гостя. Память текущей формы/request допустима временно, без обещания восстановления после перезапуска. Auth credentials регулируются Core отдельно; static asset cache не хранит private data. При неизвестном сохранении — видимое «Не сохранено» и точный идемпотентный retry; CAS/authorization и owner isolation сохраняются.

Существующий local-first storage не считается соответствующим контракту. Его замена — функциональный B0 с server validation и проверками, не декоративный PR и не новая shared инфраструктура.

## Добровольное участие и взаимная видимость знакомств

1. Постоянная вкладка → выразительный вводный экран без анкет/реальных скрытых фото/симпатий/счётчиков.
2. «Пойти знакомиться» → необходимые допуски → нужные поля/preferences → предпросмотр публикуемого слоя.
3. «Открыть профиль и знакомиться» → серверный подтверждённый opt-in → подборка. Отказ/ошибка не включает discovery.
4. **Не открыл собственный профиль для знакомств — не можешь смотреть чужую dating подборку.** Сервер проверяет актуальные viewer opt-in/profile eligibility и candidate eligibility во всех выдачах/карточках/галереях/симпатиях; прямые ссылки и кеш не обходят правило.
5. Публикуется только явно согласованный слой; приватные интересы/границы не раскрываются по факту opt-in.
6. Пауза → сервер отключил видимость и право просмотра → очистить dating содержимое → вводный экран в той же вкладке. Настройка действует на всех устройствах.
7. Обычное общение/просмотр community author profile имеют свои ACL; не путать их с dating discovery. Существующие разговоры не удаляются автоматически без отдельного контракта.

## Композиция и взаимодействия

Phone Dating: компактный заголовок → большая photo-led карточка на доступную высоту → кнопки выбора → dock; без внешней page-scroll. Полный профиль прокручивается внутри. Горизонталь выбирает, вертикаль читает; кнопки — альтернативы свайпу; resize отменяет жест. Gallery/undo/filter/empty/likes имеют законченные пути, но фикстуры не являются серверными действиями.

Моя карта показывает личное, Темы — общее. Пример: Темы объясняют «Связывание», карта содержит моё отношение/опыт/границы. Я показывает, как меня видят другие и чем я управляю. Разделы нельзя делать одинаковыми матрицами карточек с разными заголовками.

18+/consent/Premium/private access — по выбранному действию в adaptive sheet/dialog, без постоянных стен текста; restricted content не показывается до permission. Реальный риск потери ввода/неопределённого сохранения остаётся видимым. Back/Escape/focus, allowlisted return и явное подтверждение write после входа обязательны.

Geologica SHRP/CRSV, warm light/dark, rose/lilac, умеренный glow/glass, Motion transform/opacity и reduced motion — из Claude. На маленьких карточках убрать случайные декоративные SVG-орбиты. Каждый формат соответствует содержимому: карта — отметки; каталог — темы; события — дата/условия; обсуждение — текст; знакомства — фото.
