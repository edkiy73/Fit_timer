# FetUre V8 — упрощение после UX-оценки V7

14.10.2026 · Claude. Основа — V7.1 из main. Всё, о чём договорились после оценки V7.

[Открыть V8](prototype-v8.html) · [V7 для сравнения](prototype-v7.html) · исходники `apps/feture/prototype/v8/` · сборка `node apps/feture/tools/build-prototype-v8.mjs` · QA `node apps/feture/tools/qa-prototype-v8.mjs`

## Главное правило V8

Всё, что относится друг к другу, собрано в одну карточку с маленьким заголовком сверху. Варианты выбора — строки внутри одной карточки, а не отдельные плашки на фоне. Табы оставлены только там, где без них не обойтись (подборка знакомств, страница сообщества).

## Что изменено

| Тема | Как было в V7 | Как в V8 |
|---|---|---|
| Старт продукта | Онбординг вёл к тесту, «Изучить» и ленте | По шагам: интересы → сообщества для тебя → первый тест, которым можно поделиться. Знакомства в онбординге не участвуют |
| Знакомства | Вкладка «Люди» всегда в панели | Выключены, пока не наберём аудиторию (переключатель в админке, в QA-панели «Знакомства в админке»). Вкладка «Люди» появляется только при включении |
| События | Вкладка внутри ленты | Отдельный раздел в нижней панели |
| Лента | Табы «Для тебя / Подписки / События» | Без табов: «Подписки» — чип в строке фильтров |
| «Я» | Плитки Карта, Дневник, Изучить, Расширенный профиль | Карточка профиля с кнопками «Как видят» и «Изменить», баночки прямо в «Я», 12 тестов карточками, «Приватное» и «Активность» списками. Дневник и «Изучить» убраны |
| Тесты | 3 теста в «Изучить» | 12 независимых тестов с разными обложками. Тест сам предлагает баночки, они добавляются после подтверждения |
| Баночки | Отдельный блок «Границы», окно темы с 4 параметрами | Банка сама показывает состояние: интерес, «обсуждаем» или «жёсткая граница». Окно темы: что это, один переключатель состояния, уровень, кто видит |
| Баночки в чужом профиле | Нажатие ничего не делало | Открывается лист прямо на месте: что это, уровень человека и твой, «Добавить к себе» |
| Профиль | Табы Профиль / Баночки / Публикации | Одна страница: о себе, кратко, интересы, публикации, сообщества, события |
| Расширенный профиль | Отдельный экран | Продолжение профиля сразу под обычным, если доступ открыт: желания, границы баночками, фото с водяным знаком |
| «Как видят» | Баннер над фото сдвигал и обрезал фото | Фото на всю ширину сверху, пояснение — под кнопками |
| Доступы | 4 таба, последний обрезан | Одна страница: «Просят у меня», «Мои запросы», «Открыто мне», «Я открыл(а)». Отказ — нейтральная серая метка «без ответа» |
| Мои события, Мои публикации, Сохранённое | Табы | Одна страница с разделами |
| Фильтры | Длинный лист со всеми чипами | Как в Feeld: список «категория → текущий выбор»; строка открывает варианты с поиском, «Готово» возвращает к списку. Знакомства: карточки «Кого показывать», «Возраст», «Где», «Предпочтения» |
| Чипы | Галочка у выбранного сдвигала вёрстку | Галочки нет, выбор — цветом |
| Публикация | Все блоки сразу, публикация только через предпросмотр | Сначала текст и кнопки «Фото/видео», «Опрос», «Результат»; блок открывается своей карточкой. «Опубликовать» сразу, «Как увидят» — по желанию, «В черновик» — в шапке |
| Результат в публикации | Показывал 4 темы, публиковал 2; мог взять тему «по доступу» | Только темы, открытые всем; выбираешь до 4 сам; публикуется ровно выбранное |
| «Иду» на событие | Второй лист с видимостью | Одно касание. Видимость участия — только в настройках. Нижняя кнопка — только для адреса, билета, заявки; закладка в шапке |
| Закрытие листов | Молча теряли выбор, загрузка отменялась без вопроса | Окно темы, фильтры и загрузчик спрашивают перед потерей выбранного |
| Уведомления о действиях | До трёх сразу, переживали смену экрана | Одно за раз, пропадает при переходе |
| Тексты | Статичная фраза «пишем нейтрально» при любом режиме уведомлений | Фраза зависит от режима |
| Быстрые темы в ленте | Заменяли выбранное | Добавляются к выбранному |

## Как проверено

- `tools/qa-prototype-v8.mjs`: все экраны QA-панели RU и EN при 390 px и RU при 320 px — без ошибок JS, переполнений и кириллицы в EN.
- Свайпы касаниями (знакомства включаются в QA-панели), «Назад/Вперёд», сохранение черновика — пройдено.
- На реальных телефонах не проверялось.

## Решения, которые я принял сам

- Нижняя панель: Лента · События · Сообщества · Чаты · Я; при включённых знакомствах добавляется «Люди» (6 пунктов).
- Предпросмотр публикации — по желанию.
- Отказ на запрос — по-прежнему «без ответа», но нейтральным цветом.
- Страница сообщества сохранила табы (обсуждения, события, участники, правила) — там без них не обойтись.
