# FetUre — ручная работа через две подписки

**Актуальный режим:** Claude Code и ChatGPT/Codex работают **только по команде пользователя**. Автозапуск, расписание, отдельные платные model API и циклы без остановки **отменены**. Этот файл заменяет прежнюю схему Claude Routine.

1. [START](agent-team/START.md) — инструкция координатору, минимальный контекст.
2. [ISSUES](agent-team/ISSUES.md) — вся очередь до MVP/production; крупные epics, небольшие рабочие задачи.
3. [HANDOFF](agent-team/HANDOFF.md) — 12 строк для передачи работы Claude ↔ ChatGPT при окончании квоты или контекста.
4. [ROADMAP](agent-team/ROADMAP.md) — зависимости и gates этапов.
5. [Дизайн-эталон Claude](design-reference/README.md) и [UI-качество](ui-quality.md) — для интерфейса.
6. Роли: `.claude/agents/feture-*.md` и `.codex/agents/feture-*.toml` (если клиент поддерживает subagents). При отсутствии native subagent coordinator применяет роль в основной сессии, не создавая повторные длинные промпты.

**Пример команды в любом приложении:** «Продолжай FetUre: проверь свежий main, свободную P0 Issue, делай один небольшой срез по START, создай PR и короткий handoff. Дизайн сверяй с Claude HTML. Не запускай лишних агентов.»

Рабочее дерево остаётся в GitHub; пользователь может работать целиком с телефона. Открытый PR не означает завершённый или проверенный экран. Отдельный GitHub Project board сейчас не создавался: GitHub Issues уже заведены и пригодны для реальной работы; Projects UI можно добавить без миграции задач.
