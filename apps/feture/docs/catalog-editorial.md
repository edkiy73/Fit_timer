# W01 — первый редакционный выпуск

`data/catalog-editorial.json` содержит 144 кратких определения на русском,
поисковые синонимы и выборочные связи между существующими ID. Текущий выпуск
— version 1, published. Это редакционные пояснения, не инструкции, диагнозы,
оценки людей или гарантия безопасности. Определения ролей, фантазий и форматов
не превращают отметку в согласие.

Файл относится к публичному справочнику: сервер `/api/catalog` добавляет
пояснения к разрешённым taxonomy rows, React использует тот же выпуск для
live/offline каталога. ID без определения этого выпуска исключаются из
публичного списка. Поиск учитывает название, определение и синонимы, регистр
и ё/е; в направлении можно сбросить фильтр. Редактор показывает определение,
альтернативные названия и связанные темы без изменения личных ответов.

`npm run check:catalog` проверяет точное покрытие справочника, plain text,
размеры, дубли и существование related IDs. Gate входит и в check, и в build.
Черновики нельзя помещать в этот файл: он целиком входит в публичный offline
bundle. Для будущей draft/publish системы нужен отдельный приватный store,
а не переключение статуса строки в клиентском JSON. В этом срезе нет
админ-редактора, immutable версий опросников или изменения PostgreSQL.
`concept-catalog.json` и hashes/provenance seed-наборов не изменены.

Источник направления UX: приложенная концепция 3.1/план (3), помощь по
нажатию на чип и объяснение незнакомых названий. Тексты написаны для FetUre,
без копирования словарных статей. Для различения ориентации/идентичности,
добровольности согласия и согласованной немоногамии сверены:

- [Planned Parenthood — orientation and gender](https://www.plannedparenthood.org/learn/sexual-orientation-gender)
- [Planned Parenthood — consent](https://www.plannedparenthood.org/learn/relationships/sexual-consent)
- [PLAC — definitions of consensual non-monogamy and polyamory](https://polyamorylegal.org/faqs)

Полные страницы Planned Parenthood не открылись (403); использованы доступные
поисковые выдержки. PLAC прочитан полностью. Это не юридическая или медицинская
редактура. Отдельная проверка человеком и международная локализация остаются
в редакционной приёмке W01; карточка целиком ещё не закрыта.

## W01.1 — приватные черновики (GPT-6 High, 2026-10-11)

В админку добавляется редактор определений, поисковых синонимов и related IDs. Сохранение осуществляется только после Core admin authentication, через ограниченный service-role RPC и изолированную таблицу `feture_catalog_topic_drafts` с закрытым RLS. Каждый save требует ожидаемую ревизию, защищён от гонки, проверяет ID, plain text/размеры и связи. Данные никогда не считываются через `/api/catalog`, публичный сайт продолжает использовать редакционный выпуск 1. Веб и Android/iOS используют прежний bundle; до W01.2 ни одна опубликованная дефиниция не меняется.

Это **не** завершённая W01: W01.2 должен безопасно публиковать reviewed immutable versions, обновить public response/live React адаптер, протестировать кеш/старые результаты/датасеты и независимую проверку. Вся W01 `[ ]` до полной приёмки; W01.1 ждёт CI, DB migration и review.
