## Главное
- **Процесс разработки (2026-10-12): только ручной Claude Code ↔ ChatGPT/Codex по подпискам.** План MVP разбит на [8 эпиков и 33 рабочих Issues](../agent-team/ISSUES.md), включая ранее существовавшие #826/#827/#829. [Общие роли](../agent-team/START.md), [короткий handoff](../agent-team/HANDOFF.md), [эталон от Claude](../design-reference/README.md). Старые model API workflows удалены, расписания не включены; GitHub Projects-доска отдельно не создавалась. Код и задачи в Issues **не** означают live/security/device acceptance.
- **Правило слияний по решению владельца 2026-10-12:** за проверки каждого небольшого PR отвечает действующий агент, а не владелец. После CI + нужного независимого ревью агент может самостоятельно слить безопасный срез и продолжить. Невыполненные реальные device/staff/live проверки отслеживать как веху. У владельца спрашивать только про реальные policy/release/платёжные/18+/деструктивные решения; без запуска фоновых AI-ботов. Полный контракт — `apps/feture/AGENTS.md` §9 и `docs/agent-team/START.md`.
- **Подключение живого сайта, проверено 2026-10-12:** production `565ef7d` — health 200; shared Supabase connected, все пять store операций успешны. Владелец добавил server Secret и Resend key. MAIL_FROM исправлен с Gmail на `FetUre <onboarding@resend.dev>`, redeployment READY, health 200 с testDomain=true. Разработка без покупки домена: письма только владельцу Resend; реальная доставка/вход и два аккаунта ещё не проверены. AI/push/billing отключены, отдельные gates остаются открыты.
- Продукт: «Мой мир → Исследовать → Сообщество → необязательные Знакомства». Сайт открытый по ссылке; приватные функции требуют настоящих server-side прав. ПК/планшет/телефон/fold + Capacitor Android/iOS. Изменять только FetUre сущности. APK/IPA не собирать до вехи.
- **Код реализован ≠ принят в production.** CI/миграции не доказывают реальную проверку двух взрослых аккаунтов, независимый privacy audit, native QA или юридическую готовность. Большие карточки держать открытыми до таких проверок.
- **Supabase:** shared FitT project, таблицы только `feture_*`, `feture_seed.environment=prelaunch` (последняя read-only проверка). Доступ service_role через сервер; anon/authenticated напрямую приватное не читают.
- **18+:** prelaunch QA разрешение любому существующему Core аккаунту через admin, 24–72 часа, отзыв, consent отдельно; при `stage=live` недействительно. PR #799 + #801 в main, SQL `20261011083303` и `20261011113717`. **Не является production proof**. Yoti — кандидат на реальную верификацию, договор/ключи/законы ещё не подтверждены.
