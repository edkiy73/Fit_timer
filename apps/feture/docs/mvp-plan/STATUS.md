## Главное
- Продукт: «Мой мир → Исследовать → Сообщество → необязательные Знакомства». Сайт открытый по ссылке; приватные функции требуют настоящих server-side прав. ПК/планшет/телефон/fold + Capacitor Android/iOS. Изменять только FetUre сущности. APK/IPA не собирать до вехи.
- **Код реализован ≠ принят в production.** CI/миграции не доказывают реальную проверку двух взрослых аккаунтов, независимый privacy audit, native QA или юридическую готовность. Большие карточки держать открытыми до таких проверок.
- **Supabase:** shared FitT project, таблицы только `feture_*`, `feture_seed.environment=prelaunch` (последняя read-only проверка). Доступ service_role через сервер; anon/authenticated напрямую приватное не читают.
- **18+:** prelaunch QA разрешение любому существующему Core аккаунту через admin, 24–72 часа, отзыв, consent отдельно; при `stage=live` недействительно. PR #799 + #801 в main, SQL `20261011083303` и `20261011113717`. **Не является production proof**. Yoti — кандидат на реальную верификацию, договор/ключи/законы ещё не подтверждены. 1. **O02/A04:** персональные роли операторов и полноценный аудит ручного допуска; real adult proof only through verified method, отдельно от QA. Не использовать самодекларацию и не переносить QA в live.
2. **W07.3:** индивидуальные согласия обеих сторон для сравнений, только добровольно выбранные поля; независимый privacy review.
3. **C01/C02/C03/C04 → R01/R02/R03 → D01–D05:** реальные community, пары, dating; зависимости/схема — в карточках ниже. Высокорисковые права/UGC нуждаются в отдельном аудите.
