- [ ] **D03. Симпатии, undo, матч.** После D02. Idempotent decisions, like с выбранным доступным элементом/короткой запиской, входящие симпатии, бесплатная отмена последнего ещё допустимого решения. Взаимность в транзакции создаёт единственный match. Готово: повтор/две вкладки не удваивают match; после match undo не разрывает уже созданный разговор (отдельный unmatch); удалённый/скрытый target не раскрывается из цитаты лайка.
- [ ] **D04. Разрешённый чат.** После D03/P03. Match либо принятый запрос общения, не один like/follow/grant. Server membership/permission на send/read; messages cursor, clientMessageId, read cursor, optimistic sending/failed/retry, delete-for-me и явный unmatch. Для пары ограниченный conversation с подтверждёнными участниками: у сообщения индивидуальный автор, нет общего логина. Начать polling c паузой в фоне, realtime только при измеримой нужде. Готово: retry не дублирует; block/revoke contact не позволяет новые send; закрытые медиа пересчитывают ACL при чтении. Не обещать E2EE без её реализации.
- [ ] **D05. Состояния и наполненные сценарии.** После D04/R02. Seed likes/matches/access requests/conversations/expired/revoked/blocked; неверифицированный, пустая выдача, найденное совпадение, исчезнувший профиль. Готово: тестовые аккаунты проходят настоящий двухсторонний сценарий; нет автоматических фальшивых ответов от «живого» пользователя; реальные ошибки не превращаются в toast успеха.
