# Модераторы FetUre (тестовые)

Заведены 29.10.2026 для проверки модераторского кабинета. Это служебные адреса на `@feture.test` — писем туда не
приходит, вход только через админку.

| Почта | Ник | Роли | Что видит |
|---|---|---|---|
| mod-1@feture.test | mod_alisa | старший модератор + верификатор | все очереди, апелляции, проверка возраста и фото |
| mod-2@feture.test | mod_boris | модератор + поддержка | очереди фото, жалоб, событий; обращения в поддержку |
| mod-3@feture.test | mod_vera | модератор + верификатор | очереди фото и жалоб, проверка возраста и фото |

## Как войти

1. https://feture-mvp.vercel.app → «У меня уже есть аккаунт» → ввести почту модератора.
2. В другой вкладке: https://feture-mvp.vercel.app/#/admin → «Пользователи» → найти почту → «Код для входа».
3. Ввести код. В «Я» появится вход в модераторский кабинет.

## Вход с кодом из приложения (2FA, обязателен)

С 29.10.2026 модерация открывается только с кодом из приложения-аутентификатора: так аккаунт не уведут, даже украв
почту.

1. Поставить на телефон приложение-аутентификатор: Google Authenticator, «Яндекс Ключ», 1Password или похожее.
2. Войти, как выше, и открыть модераторский кабинет. Появится экран «Защита входа» с QR-кодом.
3. В приложении: «Добавить» → «Сканировать QR». Не сканируется — ввести ключ под QR вручную.
4. Ввести шесть цифр из приложения → «Подтвердить».
5. Появятся 10 кодов восстановления. Сохранить их в менеджер паролей (больше их не покажут) → «Готово».

Дальше: код спрашивается раз в 12 часов на каждом устройстве и ещё раз перед важными действиями (роли, бан, документы и
селфи). 5 неверных кодов подряд — пауза 15 минут. Телефон потерян — войти кодом восстановления (каждый работает один
раз) или попросить старшего модератора: «Модерация → Доступ → Сбросить», и подключить приложение заново.

Тестовые аккаунты mod-1/2/3 подключают приложение так же, на своём телефоне у того, кто ими пользуется. Секреты и коды
восстановления в репозиторий не кладём — он публичный.

## Выключить 2FA для тестов

Если тестер (человек или агент) не может пройти шаг с кодом из приложения: `/#/admin` → «Проверка и доступ» → «2FA для
сотрудников» → «Выключить для тестов». Пока выключено, сотрудники входят без кода (и без подключения приложения);
у обычных людей код из приложения проверяется как раньше, подключённые приложения не удаляются. Кто и когда менял —
написано в том же разделе. **После тестов включить обратно, перед запуском переключатель обязан быть включён.**
Переключается только админ-ключом (`feture.platform.staffFactor`), сотрудник сам этого сделать не может.

## Настоящие модераторы

Когда появятся живые люди: они регистрируются обычным способом, присылают свою почту, и роль выдаётся в админке
(или по просьбе — агентом) — лучше прямо перед их первым входом, чтобы приложение подключили они сами. Тестовые аккаунты выше тогда можно отключить.
