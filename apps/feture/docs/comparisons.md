# W07.3 — добровольное сравнение выбранных тем
Реализовано GPT-6 High; требуется независимая проверка Sol 6.1 и browser/native приёмка двух настоящих взрослых аккаунтов. Общая W07 не закрыта.

Получатель отзывной карточки открывает «Предложить сравнение», выбирает 1–6 сохранённых тем без границ и отдельно подтверждает использование этих отметок. UUID приглашения и точные revision выбора фиксируются до запроса: повтор не создаёт новый запрос. Владелец в «Сравнениях» видит свои ранее выбранные темы и отдельно разрешает сравнение именно для этого приглашения. До второго согласия каждый получает только свой выбор, `items=null`; чужие значения и вычисленный результат не раскрываются.

После двух согласий показываются только пересечение выбранных тем и две отметки stance, с перспективой текущего участника. Нет общего score, опыта, границ, интенсивности, личных заметок, сырых ответов тестов, email или отпечатков участников. Опросники доступны отдельным переходом; ответы и результаты сами не подтягиваются. Локальная карта не становится публичной.

`share.compare.create/list/read/approve/revoke` идут через существующий `/api/domain` и личную Core сессию. Read/create/approve требуют 18+ и текущие документы; SQL повторно проверяет обе стороны, блокировки, ограничения модерации, срок и исходную ссылку. Любое изменение/deletion/revision выбранной отметки закрывает старый результат. Approval использует CAS; повтор старого запроса не восстанавливает отзыв. List содержит только собственную операционную метаинформацию, а revoke доступен участнику и после потери возраста/согласия. Снимки экрана получателя отозвать невозможно.

SQL `20261011131037_feture_mutual_comparisons.sql` применён к FitT; только FetUre таблица, RLS и SECURITY INVOKER. Нет прямого чтения или RPC для anon/authenticated; service_role остаётся только на сервере. Остальные продукты и Core auth не изменены. Все проверочные документы/профили/proof/comparison из live SQL проверки откатились.

Проверки: полный FetUre check, PostgreSQL fixture с двумя согласиями/посторонним/повтором/CAS/редактированием/отзывом/ACL, API adult guard и closed DTO, live SQL rollback и проверка grants. Chromium fixture: выбор тем, отдельное согласие второго участника, обе перспективы и очистка после отзыва; без horizontal overflow на 320/390/768/1024/1440 px. Ответы API в браузере подставлены; live SQL проверен отдельно. Два реальных аккаунта/browser/native и независимый privacy audit остаются открыты. Security advisor: только ожидаемый INFO RLS без client policy; это закрытая серверная таблица.
