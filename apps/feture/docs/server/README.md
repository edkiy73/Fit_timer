### Чтобы включить `/api/fe`

1. Применить миграцию к базе (схема `feture` не трогает старые таблицы).
2. Задать пароль роли `feture_api` и строку подключения через пулер Supabase (transaction mode) → `FETURE_DATABASE_URL`.
3. Секреты: `FETURE_ID_PEPPER` (≥32 символа), `FETURE_MEDIA_TOKEN_SECRET` (≥32, тот же — в Worker), `FETURE_MEDIA_ORIGIN`.
4. Медиа: бакет R2 (юрисдикция `eu`), ключи `R2_ENDPOINT`, `R2_BUCKET`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`; Worker по `workers/media/wrangler.toml.example`.
5. Провайдеры проверки (CSAM, классификатор) — без них всё медиа уходит на ручную проверку; публично ничего не показывается без проверки.
6. Регион функций рядом с базой: сейчас база в Токио, функции в США — перед включением проверить регион Upstash (вход Core) и выбрать общий.
