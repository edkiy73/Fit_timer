## Проверка собранной V21

- Контракт V20 на файле V21 (`tests/prototype-v21-contract.mjs`) — проходит.
- Повторный краулер на V21: все элементы всех 80 экранов QA-панели для 4 персон и все кнопки 75 найденных листов/меню/диалогов — 0 мёртвых обработчиков (в V20 был 1), 0 JS-ошибок. Нажатия «без видимого результата» разобраны вручную: активная вкладка, уже выбранный вариант, системный выбор файла или тост, который краулер не дождался.
- Полный обход всех экранов QA-панели для персон «заполненный», «в паре» как «Мы», «новый» — без JS-ошибок, без «undefined/NaN» в тексте, без горизонтальной прокрутки.
- Матрица адаптивности 320/375/430/768/1024/1440/1920 × 35 экранов и попапов — 0 переполнений, обрезанных подписей 39 → после доработок 320 px остались только превью сообщений в чатах (многоточие по дизайну).
- Все 5 P0 перепроверены независимо реальными кликами на собранном файле: вход в пару из «Я → Моё» ведёт на Q01; блок из «Мы» не трогает личный чат; голос пары не отмечает «Я»; пост без ленты есть в «Моих публикациях»; «Подписки» пары показывают подписки пары.
- Не проверено: реальные устройства и касания, экранная клавиатура, оплата, живая пара на двух устройствах, скринридеры.
