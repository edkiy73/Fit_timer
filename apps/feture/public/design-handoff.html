Задача для Claude

  1. Проверить целые пути: Лента → профиль → Баночки → общие интересы; Люди → симпатия → Чаты → диалог; Я → карта → опрос → результат; Сообщества → правила/участники; События → участие.
  2. Переработать визуальную иерархию, пропорции, типографику, плотность, фото, карточки и окна. Не возвращать одинаковые универсальные списки, дубли заголовков и страницы с «назад» вместо вкладок.
  3. Сохранить пять разделов, счётчики, чипы профиля, баночки, взаимность в Чатах, RU/EN и темы. Проверить телефон, планшет, складной экран и компьютер.
  4. Работать небольшими связанными изменениями в текущем стеке. Сборка, проверка типов, smoke и независимое ревью обязательны; окончательная приёмка дизайна остаётся открытой.

Границы реализации

Вход — настоящая Core форма. Возраст — фактический серверный статус. Профили, баночки, переписки и прочие взаимодействия нового макета пока меняются только в памяти. Доставка, реальные доступы, квоты, RSVP, платежи и медиа требуют подключения. Не выдавать красивый переход за успешную серверную операцию.

Обычный вход в аккаунт нужен для открытия интерфейса. Эта инструкция открыта отдельно и не обходит защиту данных. Если вход недоступен, читать исходники новых компонентов, а не исследовать старый интерфейс как замену.
