# Частичные тренировки — план

Цель: FitTimer сохраняет реальную работу человека и не требует идеального завершения тренировки.

## Логика
- «Готово» — текущий подход выполнен.
- «Пропустить» — текущий подход не выполнен.
- Все подходы упражнения выполнены — упражнение выполнено полностью.
- Часть подходов выполнена — упражнение выполнено частично.
- Ни одного подхода не выполнено — упражнение пропущено.
- Фактические повторения внутри выполненного подхода пока не спрашиваем.

## Этапы
1. ✅ Защитить прогресс от потери: несколько незаконченных тренировок, удаление только нужной сессии, сохранение результата каждого подхода.
2. ✅ Добавить «Закончить на сегодня» и запись частичной тренировки в историю.
3. ✅ Считать только реально выполненные упражнения, подходы, время и объём; прогрессию повышать только по полностью выполненным упражнениям.
4. ✅ Добавить состояние «частично» на главной и в неделе; частичная тренировка не ломает серию и не вызывает напоминание о пропуске.
5. ✅ Передавать тренеру честный частичный результат и обновить синхронизацию/аналитику.
6. ✅ Закрыть сценарии тестами, включая закрытие приложения, продолжение позже и несколько сохранённых тренировок.

## Принцип
Если человек реально что-то сделал, эта работа не должна исчезать только потому, что он не дошёл до конца тренировки.
