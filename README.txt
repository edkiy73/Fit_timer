FIT TIMER — установка и обновление PWA

УСТАНОВКА
1. Загрузи все файлы на хостинг с HTTPS (index.html, manifest.webmanifest,
   sw.js, icon-192.png, icon-512.png).
2. Открой адрес на телефоне и добавь на главный экран.
   Рекомендуется Chrome: он создаёт "настоящий" WebAPK, подписанный Google,
   и Play Защита не ругается. Samsung Internet собирает APK локально без
   подписи Play — отсюда предупреждение "Подозрительное приложение".
   Это безопасно, можно нажать "Все равно установить", либо ставить из Chrome.

ОБНОВЛЕНИЕ
Service worker v2 работает по схеме network-first для страницы:
при каждом открытии с интернетом подтягивается свежая версия автоматически.
Если браузер завис на старой версии (после обновления с v1):
Samsung Internet: Меню (три полоски) -> Настройки -> Личные данные ->
Удаление данных о просмотре -> отметить "Кэш" И "Файлы cookie и данные сайтов".
Именно "данные сайтов" удаляют старый service worker (внимание: удалятся
и сохранённые программы на этом сайте).

УВЕДОМЛЕНИЯ
Напоминания о тренировке приходят, пока приложение или браузер запущены
(вкладка может быть в фоне). Полностью закрытое PWA без push-сервера
уведомления присылать не может — это ограничение платформы.
